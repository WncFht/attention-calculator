# W3 调研：Glaisher–Kinkelin 常数 ln A 的可行性（2026-09-16）

> **落地状态（2026-09-16）**：否决——结构性不可行（矩空间符号数恒压过 P 系数数），不为 lnA 建型；已验证的真恒等式收作末节备案。

任务：判定 ln A（Glaisher–Kinkelin 常数[^finch]，ln A = 1/12 − ζ′(−1) ≈ 0.2487544770337842625）能否按 kernel-spec 的"型"标准落地——(a) 区间上定号核 K(x)、(b) 矩基 ∫B_{m,n}·P·K dx 落在有限维 ℚ-span、(c) span 含目标常数符号使 solve 能解 `{C: s·coef, 1: −s·bound}`。结论：**不可行，且是结构性不可行，不是搜索预算问题**。意外的是障碍不在定号性——任务书设想的"lnΓ 在 (0,1) 变号"并不成立，lnΓ(x) 与 lnΓ(x+1) 在该区间上各自定号；真正的障碍是矩空间的符号数随 (m,n,d) 增长、永远压过 P 的未知系数个数：lnΓ 的多项式矩生成整条 ζ′(−s) 塔（广义 Glaisher 常数列 A_s），(1−x)^n 的有限差分最多削掉其中 n 个低阶符号，剩余的寄生符号维数迫使一致性条件把有理界 r 钉死在至多一个值上。精确扫描（m,n ≤ 5、P 次数 d ≤ 7）确认：**唯一自洽格点是 (m,n)=(0,0)**，它给出 r = 1/4 与唯一解 P = 1/2 − x，对应真恒等式 `ln A − 1/4 = ∫₀¹ (1/2−x) lnΓ(x+1) dx`——但被积函数在 x = 1/2 变号，不满足定号要求，于是一个可证的界也没有。同族替代目标同样死：ζ′(−1) = 1/12 − lnA 与 lnA 共二维 span（严格等价），ln√(2π) = A₀ 卡在同一台机器上。建议：不为 lnA 建型；已验证的真恒等式可收作备案（末节清单），需要数值界时只能走分解式（亦无现成零件，见"替代建议"节）。文中所有恒等式均经 `.venv/bin/python` mpmath dps=100 复核（mp.glaisher / mp.loggamma / mp.barnesg），残差 < 1e-100，清单见末节。

## 定号性更正：lnΓ 在 (0,1) 上不变号

任务书担心 lnΓ 在 (0,1) 变号，实测不成立：Γ 的唯一正极小点在 x₀ ≈ 1.4616321450（ψ(x₀) = 0），Γ(x₀) ≈ 0.885603 < 1，但该点在 (0,1) 之外。在 (0,1] 上 Γ 从 +∞ 单调降到 Γ(1) = 1，故 `lnΓ(x) > 0` 于 (0,1)（端点 lnΓ(1) = 0）；在 [0,1] 上 x+1 ∈ [1,2] 跨过极小点但两端 Γ = 1，故 `lnΓ(x+1) ≤ 0` 于 [0,1]（端点为 0，内部严格负，最深 −0.0844 在 x+1 ≈ 1.4616）。两个核形都满足条件 (a)。真正的问题全部集中在 (b)(c)。

## 矩推导：Alexeiewsky 定理与 ζ′ 塔

Alexeiewsky 定理给出 lnΓ 的初等+ Barnes G 原函数[^ww][^dlmf-barnes]：`∫₀ˣ lnΓ(t) dt = (x/2)·ln(2π) + x(1−x)/2 + x·lnΓ(x) − lnG(x+1)`（已对 x = 0.3, 0.7, 1, 1.5, 2.3 验证）。对 `x^m·lnΓ(x+1)` 做分部积分、以 Alexeiewsky 收边界，得矩通项主公式——记广义 Glaisher 常数列 `A_s := −ζ′(−s) + ρ_s`，其中 `ρ₀ = 0`、`ρ_s = B_{s+1}·H_s/(s+1)`（B 为 Bernoulli 数、H 为调和数；s ≥ 1）[^adamchik][^espinosa-moll]，则

$$I_m := \int_0^1 x^m \ln\Gamma(x)\,dx = \sum_{s=0}^{m} (-1)^s \frac{m!}{s!\,(m-s+1)!}\, A_s, \qquad J_m := \int_0^1 x^m \ln\Gamma(x+1)\,dx = I_m - \frac{1}{(m+1)^2}.$$

主公式对 m = 0..6 全部数值归零。低阶展开（J_m 形）：`J_0 = ln(2π)/2 − 1`（即平移的 Raabe 积分[^dlmf-barnes]）、`J_1 = ln(2π)/4 − lnA − 1/4`、`J_2 = ln(2π)/6 − lnA + ζ(3)/(4π²) − 1/9`、`J_3 = ln(2π)/8 − lnA + 3ζ(3)/(8π²) + ζ′(−3) − 17/360`。塔的前几层常数：`A_0 = ln√(2π)`、`A_1 = lnA`、`A_2 = ζ(3)/(4π²)`、`A_3 = −ζ′(−3) − 11/720`、`A_4 = −3ζ(5)/(4π⁴)`、`A_5 = −ζ′(−5) + 137/15120`、`A_6 = 45ζ(7)/(8π⁶)`——其中偶指标退化用了 ζ 函数方程的推论 `ζ′(−2k) = (−1)^k (2k)!·ζ(2k+1)/(2^{2k+1} π^{2k})`（k = 1,2,3 已验证），奇指标 ζ′(−3), ζ′(−5), … 是真正的新常数。配套还有一条干净的"Bernoulli 纯度"公式：`∫₀¹ B_n(x) lnΓ(x) dx = (−1)^n A_n`（n = 0..4 验证），它一次性给出 `lnA = ∫₀¹ (1/2−x) lnΓ(x) dx` 与 `lnA − 1/4 = ∫₀¹ (1/2−x) lnΓ(x+1) dx`——两条都是真恒等式，但权重 (1/2−x) 都变号。这个结构不是偶然：lnA 坐在塔的 A₁ 层，凡是把它单独提取出来的线性泛函都带变号权重（见末节 ψ 矩的同类现象）。

## 支持集规则与维数障碍

格点 (m,n) 的第 j 列矩 `M_j = ∫x^{m+j}(1−x)^n lnΓ(x+1) dx = Σ_{i=0}^{n} (−1)^i C(n,i)·J_{m+j+i}`。A_s 在 J_k 中的系数 `c_s(k) = (−1)^s k!/(s!(k−s+1)!)` 当 k ≥ s 时是 k 的 s−1 次多项式（s = 0 时是非多项式的 1/(k+1)，故 A₀ 永不消失）、当 k < s 时符号根本不存在。n 阶有限差分消去 A_s 当且仅当两个条件同时成立：s ≤ n（多项式次数 < n）且整个差分步距落在 k ≥ s 内（m+j ≥ s）。合并得精确支持集规则：

$$\operatorname{supp} M_j \;=\; \{1,\ A_0\} \;\cup\; \{\,A_s : \min(n,\, m+j) < s \le m+j+n\,\}.$$

目标常数 lnA = A₁ 出现在某列 ⟺ min(n, m+j) = 0，即 **n = 0（所有列）或 m = 0（仅 j = 0 列）**。两条路都救不了场：n = 0 行里第 j 列带符号塔 `{1, A_0, A_1, …, A_{m+j}}`，P = a₀+…+a_d x^d 的 d+1 个未知量面对 {1, A₀, A₁} 以外的 m+d+1 个寄生符号零约束——列空间左零维数 ≥ m+1，每条左零向量给 r 一个仿射条件，m ≥ 1 时条件互相矛盾、对所有 r 不自洽；m = 0、n ≥ 1 时 lnA 只能由 a₀ 携带，但塔 `{A_{n+1}, …, A_{n+d}}` 仍在，左零维数 ≥ n+1 ≥ 2，同样全 r 矛盾。只剩 (0,0)：符号 {1, A₀, …, A_d} 共 d+2 个、未知量 d+1 个，左零维数恰为 1 → r 被钉死在唯一值。解出（任意 d，解恒同）：

$$r_0 = \tfrac14,\qquad P(x) = \tfrac12 - x,\qquad \ln A - \tfrac14 = \int_0^1 \left(\tfrac12 - x\right)\ln\Gamma(x+1)\,dx.$$

恒等式为真（数值残差 4e-102），但 P 在 x = 1/2 变号——被积函数 (1/2−x)·lnΓ(x+1) 在 0.25 处取 −0.0246、0.75 处取 +0.0211，定号条件失败。即便忽略定号性，这个型也只能"证" `lnA ⋚ 1/4` 这一个孤立界（真值为 lnA ≈ 0.24875 < 1/4，差 0.0012），对任意输入 r 无回答能力——不满足型的语义。换核 `K = lnΓ(x)` 更糟：在 A_s 记账法下其矩根本没有独立的 "1" 方向（所有有理部分被吸收进 A_s 定义里），连有理界都无从表达；把 lnA 拆成 {ζ′(−1), 1} 记账只是搬走同一障碍（此时 (0,0) 钉死 r = 1/12，P = x − 1/2 仍变号）。本质原因是 Hölder 定理：Γ 不满足任何代数微分方程[^holder]，lnΓ 的多项式矩不可能坍缩进有界维数的符号空间——每加一档矩指数就多一个新常数 A_s，塔无限长高。

## 备选核形逐一评估

**K = ψ(x+1)（digamma）**：在 [0,1] 上变号——ψ(1) = −γ < 0、ψ(2) = 1−γ > 0，唯一零点 x₀ ≈ 0.46163——直接死于条件 (a)。平移到 ψ(x+2) 虽定号（> 0），但 IBP 把它的多项式矩送回同一座 A_s 塔（∫x^k ψ = 边界 lnΓ 项 + k 倍低阶 lnΓ 矩），维数障碍原样保留。附记一组已验证的 ψ-Bernoulli 矩：`∫B_1 ψ(x+1) = 1 − ln(2π)/2`、`∫B_2 ψ(x+1) = 2lnA − 1/2`、`∫B_3 ψ(x+1) = 1/12 − 3ζ(3)/(4π²)`、`∫B_4 ψ(x+1) = 1/45 − 4ζ′(−3)`——提取 lnA 的权重 B_2 = x²−x+1/6 依然在 [0,1] 变号（根 (3±√3)/6），与 lnΓ 侧的现象完全平行。**K = lnG(x+1)（Barnes G）**：在 (0,1) 内部为正、端点为 0，定号可行，且 ∫₀¹lnG(x+1)dx = 1/12 + ln(2π)/4 − 2lnA（已验证）确实含 lnA；但 lnG 的多项式矩经其对数导数 `G′/G = (z−1)ψ(z) − z + (ln2π+1)/2`[^adamchik] 回落到 ψ/lnΓ 矩——同一座塔、指标平移，寄生符号只多不少。**对称核 lnΓ(x)+lnΓ(1−x) = ln(π/sin πx)**：定号为正，但矩落在对数正弦/Clausen 塔 {lnπ, ln2, ζ(2k+1)} 里，不含 lnA；反对称核 lnΓ(x)−lnΓ(1−x) 自身变号。**半域 [0,1/2]**：半矩仍含 lnA 且新增 ζ(3)/π² 级符号（已验证 ∫₀^{1/2}x lnΓ = ln2/24 + lnπ/16 + lnA/4 − 7ζ(3)/(32π²)），塔不缩反而多一层。**复合结构（gamma 型两段式）**：gamma 核能成是因为寄生符号只有一个 ln(N+1)、且它有现成的 ln_q 子证明机器；lnA 格的寄生符号是随 (m,n,d) 增长的整条塔，单发子证明消不掉。**P 升次**：(0,0) 格 d 从 1 升到 7 解恒为同一 P = 1/2−x（高次系数被迫取 0），其余格点一致性不随 d 恢复。**混合核**（erf 文档的逃生口）：往 lnΓ 上加定号项只能加符号不能消符号，无类似 √π 缩放因子的救星。

## 替代建议

字面 `lnA ⋚ r` 在本架构内放弃。顺带说明三个邻近目标同样无路：**ζ′(−1)** = 1/12 − lnA 与 lnA 共 span{lnA, 1}，证它等价于证 lnA，同死；**ln√(2π) = A₀** 虽是塔底常数且 ∫₀¹lnΓ = A₀ 是干净的 Raabe 恒等式，但任何格点 (m,n) 的矩支持集都带 A_{s≥1} 高层符号（支持集规则：s ≤ m+j+n 的高层永不缺席），二维 span{A₀, 1} 只在退化单点 (0,0,d=0) 出现——那只剩 `∫lnΓ(x+1) = A₀ − 1` 这一条等值恒等式，同样证不了任意 r；**分解式** `lnA = (ln2π + γ)/12 − ζ′(2)/(2π²)`（函数方程对 ζ(1−s) 求导，链式负号已修正并验证）把 lnA 拆成 γ、ln(2π)、ζ′(2) 三件——γ 有型，但 ln(2π) 不是 ln_q 的有理对数、ζ′(2) 更没有型，分解路径同样缺零件。若未来要给 lnA 留资产，唯一诚实的形式是 exact 模式的**等值证书**（constant = 定积分，不证不等式），候选为 `lnA = ∫₀¹(1/2−x)lnΓ(x)dx` 与 `lnA − 1/4 = ∫₀¹(1/2−x)lnΓ(x+1)dx` 两条已验证恒等式；当前证书机制只覆盖已证界，需先扩语义，建议不做。

## 建议核形

无可建议核形——三条判据里 (b) 结构性失败。按 (a)(b)(c) 记录调研结论：

- (a) 定号核：`K(x) = lnΓ(x+1)`（[0,1] 上 ≤ 0）与 `K(x) = lnΓ(x)`（(0,1) 上 > 0）均满足定号；变号担心不成立（Γ 极小点 x₀ ≈ 1.4616 在域外）。
- (b) 矩空间：`∫x^m(1−x)^n·P·K dx ⊂ span{1, A_0, …, A_{m+n+d}}`，符号数 m+n+d+2（n=0）或 m+n+d+2 减被差分消去项——无论如何比 P 的 d+1 个未知量多；支持集规则 `supp M_j = {1, A₀} ∪ {A_s : min(n,m+j) < s ≤ m+j+n}`。维数永不闭合，(b) 失败。
- (c) 目标常数：lnA = A₁ 仅在 n = 0 或 (m=0, j=0) 列出现；唯一自洽格点 (0,0) 钉死 r = 1/4、P = 1/2−x 变号——即使 (b) 放宽也无证可发。

备案恒等式（全部 dps=100 验证）：`lnA − 1/4 = ∫₀¹(1/2−x)lnΓ(x+1)dx`；`lnA = ∫₀¹(1/2−x)lnΓ(x)dx`；`2lnA − 1/2 = ∫₀¹B_2(x)ψ(x+1)dx`；`∫₀¹lnG(x+1)dx = 1/12 + ln(2π)/4 − 2lnA`。四条被积函数均变号，只能作等值证书、不能作不等式证明。
