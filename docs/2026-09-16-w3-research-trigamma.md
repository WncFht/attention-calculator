# W3 调研：trigamma ψ′(q) 型的矩空间推导与可行性（2026-09-16）

> **落地状态（2026-09-16）**：已落地（`kernels/trigamma.py`）——`psi1_q` 按推荐方案（对称望远镜核双向二次收敛，q>0 任意有理数）注册进 `EXACT_TYPES`；实现差异见 `docs/2026-09-16-trigamma-impl-notes.md`。站端休眠 type 39（psi，分圆核，q∈{1/3,2/3}）亦已复核。

任务：判定 `ψ′(q) = Σ_{k≥0} 1/(k+q)²`（q ∈ ℚ_{>0}，trigamma/一阶多伽马）能否按 kernel-spec 的"型"标准落地，并评估候选核 `K(x) = x^{q−1}·lnx/(x−1)`。结论：**可行，且比一般设想更顺**。核恒等式 `ψ′(q) = ∫₀¹ x^{q−1}·lnx/(x−1)dx` 成立，矩空间对任意有理 q 都恰好是二维 `span_ℚ{ψ′(q), 1}`——π²csc²、Clausen、Lerch 等伴随常数**从不进入矩**；但候选核是单向核（只能证 `>`），且上逼近只有线性收敛。更好的方案是一对对称的望远镜核：`K_>(x) = x^{q−1}(x−1−lnx)/(1−x)` 证 `>`、`K_<(x) = x^{q+N−2}(1−x+x·lnx)/(1−x)` 证 `<`，两向均二次收敛、可证窗口无缝拼接，松散侧用常数尾兜底（gamma 型 N=0 先例）。作者站端 type 39（`psi`，已休眠）的真实设计是分圆核 `ln(1/x)/(1+x+x²)` 专打 q ∈ {1/3, 2/3}，矩空间 `span{ψ′(1/3), π², 1}`、双向可证，亦已逐条复核。下述每条恒等式均经 mpmath dps=100 数值复核（237 项断言全过，清单见末节）。

## 核恒等式与定号性

`1/(x−1) = −Σ_{k≥0} x^k` 在 (0,1) 内逐段收敛，逐项积分 `∫₀¹ x^{q+k−1}(−lnx)dx = 1/(q+k)²` 给出级数定义 `Σ_{k≥0} 1/(q+k)²`；右端正是 `ψ′(q)`[^dlmf-pg]。故 `ψ′(q) = −∫₀¹ x^{q−1}lnx/(1−x)dx = ∫₀¹ x^{q−1}lnx/(x−1)dx`（q>0 保证 x=0 处可积；x→1 时 lnx/(x−1)→1，正则）。

定号性：在 (0,1) 上 `lnx<0`、`x−1<0`，故 `K⁺(x) = x^{q−1}lnx/(x−1) > 0` 恒成立，零点仅在端点（x→1 极限 1，x→0 为可积端点奇性）——满足"恒不变号且零点有限"要求。2000 点扫描最小值 1.0005（q=1/2）与解析结论一致。

## 矩公式与单向性：候选核只能证 '>'

对基 `x^m(1−x)^n` 与 `P = a+bx`，记 `j ∈ {0,1}` 为 P 的幂次，`T_k(q) := Σ_{0≤i<k} 1/(q+i)²`（`T_0=0`）。由递推 `ψ′(s+1) = ψ′(s) − 1/s²`[^dlmf-pg] 得 `∫₀¹ x^{u}K⁺dx = ψ′(q+u) = ψ′(q) − T_u(q)`，于是对一般 `(m,n,j)`：

```
M⁺(m,n,j) = ∫₀¹ x^{m+j}(1−x)^n K⁺dx
          = δ_{n0}·ψ′(q) − Σ_{t=0}^{n} (−1)^t C(n,t)·T_{m+j+t}(q)
```

已核验 160 项（5 个 q × m,n∈0..3 × j∈0..1）。关键是 `n≥1` 时 `(1−x)^n/(x−1) = −(1−x)^{n−1}` 把极点正好消掉，被积函数退化为多项式×`x^{q−1}lnx` 的 beta-ln 型纯有理积分——ψ′ 行整行归零。后果有两层：(a) `(1−x)^n` 自由度对本族完全无用，二维 (m,n) 搜索退化成一维 m 扫描；(b) `n=0` 时 ψ′ 系数恒为 `P(1) = a+b`，被方向锁死——`>` 目标要求 `a+b = coef > 0`（相容），`<` 目标要求 `a+b = −coef < 0` 即 `P(1)<0`，与 `P≥0` 矛盾。故 **K⁺ 上 `<` 结构性不可证**，与 varpi/gauss 按方向换核的先例同型[^kernel-spec]。已实测：`<` 目标在 m=0,1,2 均解出 `a+b=−1`（P 非正被弃）。

`>` 方向求解：`n=0`、`a+b=coef`、`a·T_m + b·T_{m+1} = r` 给出 `a = (q+m)²(coef·T_{m+1} − r)`、`b = coef − a`；`a,b ≥ 0` 当且仅当 `r ∈ [coef·T_m, coef·T_{m+1}]`——**可证窗口是单位区间**，因 `T_m ↑ ψ′(q)`，真命题 `r < ψ′(q)` 必在唯一 m 处命中。但 `T_m` 的收敛只是线性的：`ψ′(q) − T_{m+1} ≈ 1/(q+m)`，证紧界很贵——q=1 实测 `ψ′(1)>7/5` 首中 m=3、`>3/2` m=6、`>8/5` m=21；`T_{m+1}` 距 ψ′(1)=1.6449340668482264365 的缺口 m=9→0.095、m=29→0.033、m=99→0.00995。另一个缺点：伴随常数缺位本身意味着 `>` 侧永远走"部分和逼近"，没有利用 ψ′ 的积分结构加速。

## 改进：望远镜核对 K_> / K_<（二次收敛、双向完备）

级数逐项有双边望远镜夹逼 `1/(q+i)−1/(q+i+1) < 1/(q+i)² < 1/(q+i−1)−1/(q+i)`（当 `q+i>1`），两个不等式各自对应一个非负因子——`x−1−lnx ≥ 0` 与 `1−x+x·lnx ≥ 0`（都是 `lnx ≤ x−1` 的改写）——从而给出对称的两个核：

- **`>` 核** `K_>(x) = x^{q−1}(x−1−lnx)/(1−x) ≥ 0`（q>0 全域），矩 `∫x^u K_> = ψ′(q+u) − 1/(q+u)`，即 `M_>(m,n,j) = δ_{n0}·ψ′(q) − Σ_t w_t·L_{m+j+t}`，其中下逼近 `L_u = T_u(q) + 1/(q+u)`。`ψ′(q) − L_u = Σ_{i≥u}[1/(q+i)² − 1/((q+i)(q+i+1))] ≈ 1/(2(q+u)²)`——**二次收敛**。
- **`<` 核** `K_<(x) = x^{q+N−2}(1−x+x·lnx)/(1−x) ≥ 0`，`N` 取最小整数使 `q+N>1`（q>1 → N=0；0<q≤1 → N=1；因为上界 `ψ′(s)<1/(s−1)` 只在 s>1 有效，q<1 时第一个级数项须剥出）。矩 `∫x^u K_< = 1/(q+N+u−1) − ψ′(q+N+u)`，即 `M_< = −δ_{n0}·ψ′(q) + Σ_t w_t·U_{m+j+t}`，其中上逼近 `U_u = T_{N+u}(q) + 1/(q+N+u−1)`、`U_u − ψ′(q) ≈ 1/(2(q+N+u)²)` 同为二次收敛。

矩公式已核验：K_> 侧 12 项（3 个 q × u=0..3）全过；K_< 侧一般 `(m,n,j)` 54 项全过（最差偏差 1e-80）。两核的 ψ′ 系数同样都是 `±(a+b)·δ_{n0}` 结构，所以搜索仍是一维 m 扫描、n≥1 自动出局，P 检查直接复用 `a≥0 且 a+b≥0` 规则。

可证窗口恰好无缝拼接：`L_1(m) = T_{m+1}+1/(q+m+1) = L_0(m+1)`，故 `>` 侧区间 `[L_0(m), L_0(m+1)]` 随 m 递增把 `[1/q, ψ′)` 完美剖分——每个 `r ∈ [1/q, ψ′)` 在唯一 m 命中（`a = coef·(L_{m+1}−r)/(L_{m+1}−L_m)`、`b = coef−a`）。同理 `<` 侧 `[U_0(m+1), U_0(m)]` 剖分 `(ψ′, U_0(0)]`，`U_0(0) = T_N + 1/(q+N−1)`。两侧剩下的松散端用常数尾补齐：`>` 的 `r < 1/q` 由 `∫[K_> + (1/q−r)]dx` 成立（m=0、`P=1` 矩给出 `ψ′−1/q`，余项是正常数）；`<` 的 `r > U_0(0)` 同理加 `r−U_0(0)`——与 gamma 型 N=0 的"主项+常数尾"同构[^kernel-spec]。于是**两核 + 常数尾对全部真命题完备**，不再存在方向性死区。

实测对比（q=1，coef=1）：`ψ′(1)>8/5` 在 K_> 上 m=2 命中（K⁺ 要 m=21）；`ψ′(1)>164/100` m=9 命中（K⁺ 上 1.64 已超 T_∞ 的可证范围之外需 m≈100）；缺口 `L_{m+1}` 距 ψ′：m=4→0.0147、m=9→0.00426、m=19→0.00115、m=49→1.9e-4，对比 K⁺ 同 m 的 0.18/0.095/0.049/0.020，约 100 倍优势。`<` 侧：`ψ′(1)<7/4` m=0（P=x，恒等式 `7/4−π²/6 = ∫x(1−x+xlnx)/(1−x)dx`）、`ψ′(1)<33/20` m=8、`ψ′(1/3)<21/2` m=0（a=1/9、b=8/9，U_0=12、U_1=10.3125 剖分含 10.5）。

## 作者核：ln(1/x)/(1+x+x²)（站端 type 39 `psi` 的真实设计）

站端 UI 注释列出 `psi` 型"比较 ψ′(1/2), ψ′(1/4), ψ′(3/4), ψ′(1/3), ψ′(2/3) 与有理数"[^html-ui]（线上实测 400 休眠[^audit]）；作者专栏文章第 39 种类型给出核 `ln(1/x)/(1+x+x²)` 与三行矩[^article]。推导与复核如下。`1/(1+x+x²) = (1−x)/(1−x³) = (1−x)Σ_k x^{3k}`，故

```
J(u) = ∫₀¹ x^u ln(1/x)/(1+x+x²) dx = [ψ′((u+1)/3) − ψ′((u+2)/3)]/9     (u=0..8 已核验)
```

由递推与反射 `ψ′(1/3)+ψ′(2/3) = π²csc²(π/3) = 4π²/3`[^dlmf-refl]，J(u) 按 `u mod 3` 约化进 `span_ℚ{ψ′(1/3), π², 1}`（u=0..8 逐条核验，与文章印出的三行矩逐分母一致）：

```
u=3k  : ( 2/9)·ψ′(1/3) − (4/27)·π² + Σ_{i<k}[1/(3i+2)² − 1/(3i+1)²]
u=3k+1: (−1/9)·ψ′(1/3) + (7/54)·π² + H_k⁽²⁾/9 − Σ_{i<k} 1/(3i+2)²
u=3k+2: (−1/9)·ψ′(1/3) + (1/54)·π² − H_k⁽²⁾/9 + Σ_{i≤k} 1/(3i+1)²
```

两个结构性优点：(a) ψ′ 系数取 `+2/9` 或 `−1/9` 两个符号，`(1−x)^n` 混合不消去（每项 J 都是两个 ψ′ 之差，不随 t 伸缩）——**双向可证**，二维 (m,n) 搜索保持有效；(b) 核恒非负（`ln(1/x)≥0`、分母恒正，最小扫描值 1.67e-4>0，x→1 处→0）。代价是每条矩都带非零 π² 系数，三维 span 需要处理寄生符号：作者的做法是**复合**——把 π² 子证明的被积函数并进同一积分（文章例 `ψ′(1/3)<21/2` = `π²/2<21/4` 的 pi_n 子证明 + 核积分 `∫3x²(1−x)(4x(1+x)/(1+x²)+1/(1+x+x²))ln(1/x)dx`，已核验其值恰为 `21/2−ψ′(1/3)`）；更干净的等价做法是 `P = a+bx+cx²` 三系数直接解（π² 行置 0），实测 `ψ′(1/3)<21/2` 在 (m,n)=(0,1) 命中 `P=1−3.5x+4x²`、`>9` 在 (0,1) 命中 `P=1+5.5x−2x²`、`<10.5`、`<10.51` 均在 (0,1)，假命题 `ψ′(1/3)<10` 在 (m,n)≤10 内正确地无解。

对 `ψ′(2/3)` 由反射 `ψ′(2/3) = 4π²/3 − ψ′(1/3)` 归约——目标行系数取反即可，同一台机器。该核原则上推广到其他分母：`1−x+x²`、`1+x²+x⁴` 等分圆分母给出六分之一、八分之一参数的 ψ′ 差分，但作者只用了 1/3 一族。

## 参数域与常数谱系

研究问题"非整数 ψ′(p/r) 是否携带 π²csc²/Clausen 伴随项"的答案是：**核矩层面不产生任何伴随常数**——K_>/K_< 的矩闭式对任意有理 q 恰为 `{ψ′(q), 有理数}`（n≥1 退化为纯有理），π²csc²、Clausen、Lerch 只在把常数本身改写成初等组合时才出现。按分母的归约谱系（全部已核验）：`den 1`：`ψ′(n) = π²/6 − H_{n−1}⁽²⁾ ∈ span{π²,1}`；`den 2`：`ψ′(1/2) = π²/2`、`ψ′(n+1/2) = π²/2 − 4Σ_{i<n}1/(2i+1)²` 同 span；`den 4`：`ψ′(1/4) = π²+8C`、`ψ′(3/4) = π²−8C ∈ span{π²,C,1}`；`den 3`：`ψ′(1/3) = 2π²/3 + (9/2)·L(2,χ₋₃) = 2π²/3 + 2√3·Cl2(π/3)`，是真 Lerch/Clausen 常数（`L(2,χ₋₃) = 0.7813024128964862968671874...`）；`den≥5`：单个值仍为 Lerch 超越常数，且反射和 `ψ′(p/r)+ψ′(1−p/r) = π²csc²(πp/r)` 连系数都出有理数域（`csc²(π/5) = (10+2√5)/5`）[^dlmf-refl][^dlmf-lerch]。

由此三点评估：(1) 整数 q 与半整数 q 在数学上冗余于 π² 覆盖（pi_n k=2 走 η(2)=π²/12 同 span），但实现上**不值得特判归约**——统一以 `ψ′(q)` 为符号更简，且 ψ′(n) 型比较在展示层本就是"π²/6 家族"的合理一员；(2) den 4 若想要更初等的常数表，可复用 quadlog 已有核 `ln(1/x)/(1+x²)` + 全奇偶基 + 三系数 P 在 `span{C,π²,1}` 内直接解 `{π²:1, C:8, 1:∓r}`——已实测双向可行（`ψ′(1/4)>17` 在 (3,1)、`<86/5` 在 (3,5)、`>1719/100` 在 (4,3) 命中，假命题 `<17.1`、`>18` 正确拒证），矩机器就是现成的 `ln_moment` r=1 行；(3) den≥5 照常可证（符号就是 `ψ′(p/r)` 本身，certified_cmp 走 `mp.psi(1, mpf(q))` 即可），只是常数没有更初等的写法。推荐参数域：**`q ∈ ℚ_{>0}` 全域接受**（站端只列五个参数是展示选择而非数学限制）；`q<0` 非整数可经递推右移到 (0,1) 再证（列为可选扩展，首版不做）；`q ∈ ℤ_{≤0}` 是 ψ′ 极点，输入层排除。

主推荐是望远镜核对（对称、二次收敛、全域覆盖），作者分圆核作为 fidelity 备选保留。域均 [0,1]，基 `x^m(1−x)^n`（ψ′ 行只在 n=0 存活，实际一维 m 扫描），`P = a+bx`、非负判据 `a≥0 且 a+b≥0` 原样复用，目标符号 `psi_q`（power 槽载 q=p/r，文本建议 `\psi_1(p/r)` 或按站端风格）。
