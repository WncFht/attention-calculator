# W3 调研：erf 型的矩空间推导与可行性（2026-09-16）

任务：判定 `erf(q) = (2/√π)∫₀^q e^{−t²}dt`（q ∈ ℚ）能否按 kernel-spec 的"型"标准落地——(a) 区间上定号核 K(x)、(b) 矩基 ∫x^m(1−x)^n·P(x)·K(x)dx 落在有限维 ℚ-span、(c) span 含目标常数符号。结论：**字面意义的 `erf(q) ⋚ r` 在纯 `e^{−q²x²}` 矩机器内不可达**，障碍是 erf 的定义积分天然携带 √π，缩放不进 ℚ-span；但同一台机器直接产出两个干净的可行型——**缩放常数 G(q) := ∫₀^q e^{−t²}dt = √π·erf(q)/2** 与 **Dawson 函数 F(q) = e^{−q²}∫₀^q e^{t²}dt**，外加同构第三型 **H(q) := ∫₀^q e^{t²}dt = √π·erfi(q)/2**。下述每条恒等式均经 mpmath dps=100 数值复核（清单见末节）。

## 矩推导：核 e^{−q²x²} 于 [0,1]

记 `I_m = ∫₀¹ x^m e^{−q²x²} dx`。对 `x^{m−1}e^{−q²x²}` 求导得 `(m−1)x^{m−2}e^{−q²x²} − 2q²x^m e^{−q²x²}`，两端在 [0,1] 积分即出递推；基例 I_0 由代换 t=qx 化回 erf 定义式，I_1 有初等原函数[^dlmf-erf]：

- `I_0 = √π·erf(q)/(2q) = G(q)/q`
- `I_1 = (1 − e^{−q²})/(2q²)`
- `I_m = (m−1)/(2q²)·I_{m−2} − e^{−q²}/(2q²)`（m ≥ 2；m=1 时端点项为 `e^{−q²}−1`，公式自洽）

奇偶两条链各自闭合且结构不对称——边界项 `[x^{m−1}e^{−q²x²}]₀¹ = e^{−q²}` 恒落在 e^{−q²} 符号上，永不产生裸有理数：

- 偶链 `I_{2k} = A_k·I_0 + B_k·e^{−q²}`，A_k, B_k ∈ ℚ(q)。例如 q=1 时 I_2 = (1/2)I_0 − (1/2)e^{−1}、I_4 = (3/4)I_0 − (5/4)e^{−1}、I_6 = (15/8)I_0 − (29/8)e^{−1}（已数值核验）。
- 奇链 `I_{2k+1} = C_k·1 + D_k·e^{−q²}`。例如 q=1 时 I_3 = 1/2 − e^{−1}、I_5 = 1 − (5/2)e^{−1}、I_7 = 3 − 8e^{−1}。

合并后矩空间为三维 `span_ℚ{G(q), e^{−q²}, 1}`——与任务设想的 `{erf(q), e^{−q²}, 1}` 相差一个 √π：进 span 的常数不是 erf(q) 本身，而是 `G(q) = √π·erf(q)/2`。伴随常数 e^{−q²} 即 e_q 型在 power=−q² 处的常数，符号表记 `e^{-q^2}` 之类即可。基函数 `(1−x)^n` 经二项展开 `∫x^{m+j}(1−x)^n·K = Σ_i (−1)^i C(n,i) I_{m+j+i}` 保持在 span 内（已核验）；三维 span 配三系数 `P = a+bx+cx²`，非负判据用 engine.poly_nonneg 的二次规则，与 sin_q 三维 span `{sin q, cos q, 1}` 完全同构。

## √π 障碍：为什么字面 erf(q) 不可达

上述 span 中承载目标常数的唯一方向是 G(q)=√π·erf(q)/2——所有矩的 erf 分量都以 `ℚ·√π·erf(q)` 形式出现（每条矩都从 I_0 派生，I_0 自带 √π）。要证 `erf(q) ⋚ r` 需要某矩带有理系数的 erf(q)，只能把核整体乘 `2q/√π`；但该因子不是现有符号值的 ℚ 倍——乘完后矩空间变为 `span{erf(q), e^{−q²}/√π, 1/√π}`，**这个空间里没有任何取有理数值的符号**，界项 `−s·r`（r≠0 有理数）无处安放：目标向量 `{erf: s·power, 1: −s·r}` 中 "1" 方向的值域是 `ℚ/√π`，除 0 外全是无理数。这不是搜不到解的问题，是恒等式本身不可能成形——形如 `erf(q) − r = ∫（非负被积函数）` 的等式右侧永远缺一个有理数项。gamma 型两段式复合也救不了它：子证明只能证有理界命题，而 `erf(q)⋚r` 归约到缩放常数需要无理界 `r·√π`。

唯一逃逸口是混合核 `K(x) = (2q/√π)·e^{−q²x²} + c`（c ∈ ℚ_{>0}）：第二项贡献纯有理矩 `c/(m+1)`，span 变四维 `{erf(q), e^{−q²}/√π, 1/√π, 1}`，界有了 "1" 符号。代价是 P 需升到三次 `a+bx+cx²+dx³`（四个系数解四符号），非负判据超出现有二次规则（需对三次导数根做代数数层面的精确判号），被积函数也变成指数函数与有理函数的混合两截。数学上可行、工程上笨重，不建议首版；记此备案。

需要说明：符号表的 ℚ-线性无关性（如 e^{−q²} 的超越性由 Lindemann–Weierstrass 保证[^lw]，√π·erf(q) 与其余两符号的独立性没有现成定理）不影响正确性——Moment 字典相等是 ℚ 上的全称恒等式，隐藏关系至多让个别 (m,n) 的矩系统奇异被 gauss_solve 跳过，不会产生假恒等式。

## Dawson F(q)：同族干净可达

把指数取反，核 `e^{+q²x²}` 给出 `J_m = ∫₀¹ x^m e^{q²x²}dx`，同样 IBP 得 `J_m = e^{q²}/(2q²) − (m−1)/(2q²)·J_{m−2}`，基例 `J_0 = e^{q²}F(q)/q`、`J_1 = (e^{q²}−1)/(2q²)`，span `{e^{q²}F(q)/q, e^{q²}, 1}`[^dlmf-dawson]。关键在于 Dawson 的归一化因子 `q·e^{−q²}` 本身是符号值（e^{−q²}）的有理倍——把核乘它得到 `K_D(x) = q·e^{q²(x²−1)}`，矩空间同构地映成 `span{F(q), e^{−q²}, 1}`：**F(q) 以有理系数直接出现，且 "1" 符号完好**。归一化后矩公式为

- `J'_0 = F(q)`
- `J'_1 = (1 − e^{−q²})/(2q)`
- `J'_m = 1/(2q) − (m−1)/(2q²)·J'_{m−2}`（m ≥ 2）

这正是 erf 做不到的事：erf 的归一化因子 `2q/√π` 不在符号值群里，Dawson 的在。不乘归一化因子、直接用 `e^{q²x²}` 核则证明缩放常数 `H(q) = ∫₀^q e^{t²}dt = √π·erfi(q)/2 ⋚ r`（span `{H(q), e^{q²}, 1}`，寄生符号 e^{q²} 同样是 e_q 型常数）——与 G(q) 型共用同一台机器、只差符号。

## 顺带评估：erfc / erfi / Faddeeva / Fresnel

**erfc(q)**：字面上归约为 `1 − erf(q)`，同死。直接造核：尾部积分经 t=q/x 代换得 `[0,1]` 上核 `q·x^{−2}e^{−q²/x²}`，矩 `M_m = (q^m/2)·Γ((1−m)/2, q²)` 经不完全伽马递推 `Γ(s+1,z)=sΓ(s,z)+z^s e^{−z}`[^dlmf-ig] 展开——已核验 `M_0 = √π·erfc(q)/2`、`M_1 = (q/2)·E₁(q²)`、`M_2 = −q²√π·erfc(q) + q·e^{−q²}`、`M_3 = −(q³/2)E₁(q²) + (q/2)e^{−q²}`。span 为 `{√π·erfc(q), E₁(q²), e^{−q²}}`：比 erf 更糟，多一个 E₁ 寄生符号且**完全没有纯有理方向**，界无家可归。不可行。

**erfi(q)**：同上，字面型死于 √π；缩放型 H(q) 可行（见上节）。**Faddeeva w(z)**：实轴上取复值，无实定号核，出局。**Fresnel C/S**：核 sin(q²x²) 的原函数仍是 Fresnel，IBP 不闭合，出局。

## 建议核形

三型共用一台机器（偶链/奇链结构相同、仅符号与常数项不同），实现上可一个文件承载。域均取 x ∈ [0,1]，基 `x^m(1−x)^n`，P 一律 `a+bx+cx²`（三维 span 需三系数），搜索上限建议沿用非 e/pi 型的 10。

| 型（建议名） | 常数 | 核 K(x) | 矩基例 | span 符号表 | 定号性 | q 合法域 |
|---|---|---|---|---|---|---|
| `gaussint_q` | G(q)=∫₀^q e^{−t²}dt = √πerf(q)/2 | `e^{−q²x²}` | `I_0=G(q)/q`, `I_1=(1−e^{−q²})/(2q²)`, `I_m=(m−1)/(2q²)·I_{m−2}−e^{−q²}/(2q²)` | `{G_q, e^{-q^2}, 1}` | K>0 | q>0；q<0 经 G 奇性翻向归约；q=0 退化（1/q） |
| `dawson_q` | F(q)=e^{−q²}∫₀^q e^{t²}dt | `q·e^{q²(x²−1)}` | `J'_0=F(q)`, `J'_1=(1−e^{−q²})/(2q)`, `J'_m=1/(2q)−(m−1)/(2q²)·J'_{m−2}` | `{F_q, e^{-q^2}, 1}` | K>0（q>0） | q>0；q<0 经 F 奇性归约；q=0 退化 |

字面 `erf(q) ⋚ r` 若一定要做，只有混合核 `(2q/√π)e^{−q²x²}+c` + 四维 span `{erf_q, e^{-q^2}/√π, 1/√π, 1}` + 三次 P 一条路，需新写三次非负判据，建议不进首批。退化边界统一 q=0 排除（核塌缩为常数/零，递推含 1/q²）；q<0 全部经奇函数归约到 q>0 翻方向，与 sin_q 族同处理。

## 数值核验记录

核验脚本 `/tmp/erf_verify.py`（mpmath dps=100，`.venv/bin/python`），全部断言误差 < 1e-90：

- `I_0 = √π·erf(q)/(2q)`、`I_1 = (1−e^{−q²})/(2q²)`、递推 m=2..8：q ∈ {1/2, 1, 3/2, 2} 全过。
- 偶链闭式 `I_{2k} = A_k·I_0 + B_k·e^{−q²}`（k=1..4）与奇链闭式 `I_{2k+1} = C_k + D_k·e^{−q²}`（k=1..3）：各 q 全过，确认偶链无纯有理分量。
- 二项组装 `∫x^{m+j}(1−x)^n e^{−q²x²}dx = Σ_i (−1)^i C(n,i) I_{m+j+i}`：(m,n,j) ∈ {(1,1,0), (2,3,1), (0,2,2)} 全过。
- Dawson 归一化矩 `J'_0 = F(q)`、`J'_1`、递推 m=2..8：q ∈ {1/2, 1, 3/2, 2} 全过（F 按定义 `e^{−q²}∫₀^q e^{t²}dt` 数值积分）。
- erfc 核四条闭式 `M_0..M_3`（q=1）全过，确认 span 无有理方向。
- 端到端精确求解（Fraction 矩 → engine.gauss_solve → poly_nonneg）：`G(1) > 7/10` 在 (m,n)=(2,0) 命中，恒等式 `√π·erf(1)/2 − 7/10 = ∫₀¹ x²(4−7x+4x²)e^{−x²}/5 dx` 核验通过（P 顶点 4ac−b²=3/5>0）；`F(1) > 1/2` 在 (0,1) 命中，`F(1) − 1/2 = ∫₀¹ x(1−x)²e^{x²−1}dx` 核验通过。
