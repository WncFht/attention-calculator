## 现有格点回顾：c=1/2 核的四类矩

lemniscate 机器的全部内容来自 `J_k = ∫₀¹ x^k/√(1−x⁴) dx = (1/4)B((k+1)/4, 1/2)`：按 k mod 4 分四类，`J_{4j} ∈ ℚ·ϖ`、`J_{4j+1} ∈ ℚ·π`、`J_{4j+2} ∈ ℚ·G⁻¹`、`J_{4j+3} ∈ ℚ`，其中 `ϖ = (1/2)B(1/4,1/2) = g²/(2√(2π))`、`G = ϖ/π = g²/(2π)^{3/2}`[^art]。固定基 `x^{4m+res}(1−x)(a+bx⁴)` 的 `(1−x)` 因子把相邻两个残差类拼成一个二维 span——站端四型正是四个 `{残差类, 有理类}` 配对：`varpi '<'` 取 res=3 的 `{ϖ, 1}`、`varpi '>'` 取 res=1 再整体除 π 的 `{ϖ⁻¹, 1}`、`gauss` 两型同理。要害是：**有理方向完全依赖恰好存在一个取纯有理值的残差类**（k ≡ 3 mod 4 时 `J_k = d_j/2 ∈ ℚ`），目标常数只能是它的邻居类。

## 奇偶引理：为什么 Γ(1/4) 永远不会单独出现

对 `a, b ∈ ¼ℤ`，写 `a ≡ i/4, b ≡ j/4, a+b ≡ k/4 (mod 1)`，令 `ε` 在 ℤ₄ 上取 `(0,1,0,−1)`（即 `ε(1)=+1` 对应 Γ(1/4)=g、`ε(3)=−1` 对应 `Γ(3/4)=π√2/g`、`ε(0)=ε(2)=0` 对应有理数/√π）[^dlmf-refl]。由 `Γ(x+n)/Γ(x) ∈ ℚ` 与余元公式，`B(a,b) = Γ(a)Γ(b)/Γ(a+b)` 的 g-指数为 `E = ε(i)+ε(j)−ε(k)`；而 i, j, i+j mod 2 中奇数个数恒为偶数，故 **E ∈ {−2, 0, 2}——g 只以偶次幂出现在 quarter-格点的 beta 值里**，π 幂次任意、并可能附带 √2 因子（来自 `sin(π/4)=√2/2`）。数值核验：a,b 跑遍 `{1/4, 1/2, 3/4, 1, 5/4, 3/2, 7/4, 2, 5/2}` 全部 80 余组合，每对都精确吻合预测闭式（如 `B(1/4,1/4) = g²/√π = 2√2·ϖ`、`B(3/4,1/4) = π√2`、`B(3/4,1/2) = 2G⁻¹`），E 实测只取 {−2, 0, 2}。

由此四条推论，逐条封死直接型：

第一，`x^α(1−x⁴)^{c−1}` 形核的矩按 x-指数 mod 4 分类，类符号为 `Γ(a_r)Γ(c)/Γ(a_r+c)` 的 ℚ 倍——c ∈ ¼ℤ 时永远落在偶格点；c ∉ ¼ℤ 时 `Γ(c)/Γ(a_r+c)` 是不含 g 的新超越数（如 c=1/3 时 Γ(7/12)），更不可能是纯 g。同一 (a mod 1, c) 类内所有矩只差有理因子——`B(m+a, n+b)/B(a,b) = (a)_m(b)_n/(a+b)_{m+n} ∈ ℚ`（a,b ∈ ℚ 时成立）——所以格点刻画是完备的，不存在漏网的 (m,n)。

第二，`g` 不能被现有符号集线性表出：`span_ℚ{ϖ, ϖ⁻¹, G, G⁻¹, π, 1}` 的元素全在偶格点 `g^{±2}π^{k/2}` 与 `π^k` 上；若 `g` 是其 ℚ-线性组合，消去分母即得 g 与 π 在 ℚ̄ 上的代数关系，与 Chudnovsky 证明的 `π` 和 `Γ(1/4)` 代数无关矛盾[^chud]。

第三，`g²` 作为目标符号也不可达：把 r≡0 类（值 `ℚ·ϖ`）归一到 `g²` 需要核预因子 `λ = g²/ϖ = 2√(2π)`——本身合法（与站端 `1/π` 预因子同性质），但同一 λ 把 r≡3 有理类变成 `ℚ·√(2π)`，界项 `−s·r`（r ∈ ℚ）无处安放。一个预因子只能归一一个残差类，这是硬约束——兜底模板 `∫f + b` 也救不了：模板需要核段同时产出常数与有理数两个方向，归一后只剩 `{g², √(2π)}`。

第四，更细分母格点不产生 `g¹`：乘法定理把 ⅛-格点折回 ¼-格点（如 `Γ(1/8)Γ(5/8) = 2^{3/4}√π·g`，已核验），Γ(1/8) 类值仍是独立超越数，含 g 的项仍成对出现。

## 非 beta 逃逸路径（逐一点评，皆不通）

Γ 积分 `Γ(1/4) = ∫₀^∞ t^{−3/4}e^{−t}dt` 在无界域上，`x^m(1−x)^n` 基不可用；代换 `t = −ln x` 回 [0,1] 得核 `(−ln x)^{−3/4}`，其矩 `∫₀¹ x^m(−ln x)^{−3/4}dx = g/(m+1)^{1/4}` 携带随 m 漂移的代数因子，ℚ-span 不闭合。

复合指数核有一线理论可能但工程上无价值：`K(x) = x^{−3/4}e^{−x} + x^{−5/4}e^{−1/x}` 在 [0,1] 上正定号，m=0 给出干净恒等式 `∫₀¹ K dx = γ(1/4,1) + Γ(1/4,1) = g`（已核验，其中第二段经 `x→1/t` 正好是 `∫₁^∞ t^{−3/4}e^{−t}dt`）；但一般矩落 `span{γ(1/4,1), Γ(1/4,1), e^{−1}}`——两条不完全 Γ 递推各带 `±e^{−1}` 余项[^dlmf-ig]，整个 span 没有有理方向，界只能靠 `+b` 附加常数承担，而系数约束迫使 `b = −r < 0`，证明形状塌缩；再补一段 `(1−x)^{−3/4}` 把有理方向找回来则要解四约束三未知数的超定系统，覆盖稀疏且证明只是"两个不完全 Γ 周期之差"，无启发性。不建议。

自指归一化同样不通：取 `λ = 4Γ(3/4)/√π = 4√(2π)/g` 可使 `λ·J_0 = g` 精确成立（已核验），但核里藏了目标常数的共轭 Γ(3/4)，且 r≡3 类被污染为 `ℚ·Γ(3/4)/√π`，有理方向仍缺——双重死。

与周期理论的图景一致：`g` 的奇次幂不是代数被积函数在有界有理域上的周期，`ϖ = g²/(2√(2π))`、`G⁻¹` 这类偶格点元素才是[^kz]。这也解释了为什么站端/作者所有的 lemniscate 核都只产出 ϖ、G 两族常数。

## 作者原方案（文章第 37 型）：复合证明机器已全部现成

作者对 `Γ(1/4), Γ(3/4)` 的处理不是新核，而是复用 lemniscate 矩再配辅助界[^art]：res=1/π 核给 `∫₀¹ x(1−x)(a+bx⁴)/(π√(1−x⁴))dx = (a/4+b/8) − (a+3b/5)·√(2π)/g² = (a/4+b/8) − (a+3b/5)·Γ(3/4)²/(π√(2π))`（g 下界 / Γ(3/4) 上界），res=3 核给 `∫₀¹ x³(1−x)(a+bx⁴)/√(1−x⁴)dx = (a/2+b/3) − (a/12+5b/84)·g²/√(2π)`（g 上界 / Γ(3/4) 下界）——两式已按多组 (a,b) 精确核验。这就是仓内 varpi 两核原样：记 `S := g²/√(2π) = 2ϖ`，`varpi '<'` 证 `ϖ < r₁/2` 即 `S < r₁`，`varpi '>'` 证 `ϖ⁻¹ < Q` 即 `S > 1/(2Q)` 形下界。

再往后是纯复合：证 `g ⋚ r`（r ∈ ℚ）时 r ≤ 0 平凡分流（'>' 恒真、'<' 方向反了），r > 0 时 `g ⋚ r ⟺ g² ⋚ r² = S·√(2π) ⋚ r²`。取有理数 `r₁ > S`、`r₂ > √(2π)` 使 `r₁r₂ ≤ r²` 即得上界证明；下界对称（`r₁ < S`、`r₂ < √(2π)`、`r₁r₂ ≥ r²`）。分配可行性：真命题给出严格空隙 `r² > ST`（T := √(2π)），开区间 `(T, r²/S)` 非空——任取有理 `r₂` 落其中（由 pi 型证 `π < r₂²/2` 得 `√(2π) < r₂`），再取有理 `r₁ ∈ (S, r²/r₂]`（由 varpi '<' 证）。三张证书全部是现有核型的有理界命题，`r₁r₂ ⋚ r²` 是 ℚ 上精确比较；唯一的"无理步"是开平方，而它只作用在数的大小比较上、不进恒等式。作者的 `√(2π)` 算例本身也是 pi 型积分：`(220/87)² − 2π = ∫₀¹ 2x²(1−x²)²(2432−91x²)/(2523(1+x²))dx`（已核验恒等式成立，`√(2π) < 220/87` 由此得证）。`Γ(3/4) ⋚ r` 经反射 `Γ(3/4) = π√2/g` 归约到同一对证书链（方向翻转、多一步 `π√2` 界，`Γ(1/2) = √π` 则只消 `π ⋚ r²`）。

诚实记录两处糙点：其一，文章 11/3 算例所印等式按字面值不成立——数值核验积分 `∫x³(1−x)(1361−287x⁴)/(110√(1−x⁴))dx = 319/60 − (2023/2310)·S ≈ 0.7241`，而所印 LHS 把 S-系数归一成 1（真按 `{S:1, 1:−319/60}` 求解得 a=−17/2，非负性本就过不去）；机制正确、算例失真。其二，站端从未上线该型——29 型无 Γ 项，休眠名里也只有 `Gamma_1_3_2_3`（第 38 型）而无 Γ(1/4)[^audit]——与"Γ(1/4) 无新核可立"的结构性事实吻合。

## lemniscate 族剩余单核型清单

`(1−x⁴)^{c−1}` 全族扫描（类值均已核验）：`c=1/2` 即现有 `{ϖ, π, G⁻¹, 1}`；`c=3/2`（`√(1−x⁴)` 在分子，兜底模板所用）同格点；`c=1/4` 得 `{√2ϖ, ϖ, √2π, 1}`；`c=3/4` 得 `{√2π, G⁻¹, √2G⁻¹, 1}`。新配对只有邻接有理类（r≡3）的两个：`c=1/4` res=2 给 `{√2π, 1}`、`c=3/4` res=3 给 `{1, √2π}`——同一常数 `π√2 = Γ(1/4)Γ(3/4)`（余元公式，平凡）；以及两个无命名价值的丑型 `{√2ϖ, 1}`（c=1/4 res=3 配对）与 `{√2G⁻¹, 1}`（c=3/4 res=2 配对）。c 取其它有理数只引入 `Γ(c)`-族新超越数，无命名常数。

## 建议核形

字面 `Γ(1/4)`：**不立核型**。建议按作者机制在 exact/decompose 层实现复合命题 `gamma14 ⋚ r`：证书 = (varpi '<' 或 '>' 子证，证 `S = 2ϖ ⋚ r₁`) + (pi 子证，证 `π ⋚ r₂²/2` 即 `√(2π) ⋚ r₂`) + (ℚ 精确合成 `r₁r₂ ⋚ r²`) + (开方转移)——W5 证书格式需支持复合节点；分配器按第四节开区间取有理 `r₂, r₁`。`Γ(3/4)` 同构（反射 + 额外 π√2 或 π/√2 界证书），`Γ(1/2)` 只消 pi 型加开方。

最贴近的可行单核型是 **`pi_sqrt2`（常数 `π√2`）**，作为 lemniscate 族的完备性收尾，规格如下：

- 域 `[0,1]`；'>' 方向核 `K(x) = (1−x⁴)^{-3/4}`，基 `x^{4m+2}(1−x)(a+bx⁴)`，矩 `{S: u_{m+i}/4, 1: −v_{m+i}}`（i=0,1 对应 a,b 槽位），`u_j = (3/4)_j/j!`、`v_j = (1)_j/(5/4)_j`（即 `J'_{4j+2} = u_j·π√2/4`、`J'_{4j+3} = v_j`）。
- '<' 方向核 `K(x) = (1−x⁴)^{-1/4}`，基 `x^{4m+3}(1−x)(a+bx⁴)`，矩 `{1: w_{m+i}, S: −z_{m+i}}`，`w_j = (1/3)·(1)_j/(7/4)_j`、`z_j = (1/16)·(5/4)_j/(2)_j`（即 `J''_{4j+3} = w_j`、`J''_{4j+4} = z_j·π√2`）。
- 定号性：两核在 [0,1) 上恒正，端点奇异指数 `−3/4`、`−1/4` 均可积；基在 [0,1] 非负；`P = a+bx⁴` 非负 ⟺ `a ≥ 0 且 a+b ≥ 0`（engine.poly_nonneg 偶核规则现成）。
- 求解与 varpi/gauss 完全同构：`n` 退化为方向标志、单参数 m 扫描；目标 `{S: s·power, 1: −s·bound}`。实测覆盖：'>' 侧界距 S 0.043 → m=5、0.003 → m=95；'<' 侧 0.057 → m=13、0.007 → m=116——深度随 `C/|S−r|` 增长、'<' 常数约为 '>' 的 3~4 倍，exact 模式可沿用 `EXACT_LT_LIMIT = 256` 一档。端到端已验证：m=5 发射的 `∫x^{22}(1−x)(2577291/5992448 + 5499385/749056·x⁴)(1−x⁴)^{-3/4}dx = π√2 − 22/5` 数值精确成立。
- 产品价值评估：低——常数本身是 √2·π，作者文中也只在复合链里用它；但它确是 lemniscate 格点上唯一还空着的干净型，实现只需把 `lemniscate_table` 参数化到 c，成本近零。要不要收进类型表由产品面决定。

不建议的立型：`√2ϖ`、`√2G⁻¹`（常数无意义）、复合指数核（见第三节）、`g²` 目标（有理方向被 √π 污染）。
