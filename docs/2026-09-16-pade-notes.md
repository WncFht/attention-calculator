## 构造

对级数 $f(x)=\sum c_k x^k$（`ln(1+x)` 或 `arctan x`），$[L/M]$ Padé 逼近 $P/Q$ 由 ℚ 上线性系统解出：分母系数 $q_1..q_M$（$q_0=1$）满足 $\sum_j q_j c_{k-j} = -c_k$（$k=L+1..L+M$），分子取 $Qf$ 截断到 $L$ 次。求解用 `engine.gauss_solve`，全程 `Fraction`，不查文献闭式。

两族（站端类型名 → 逼近度、首个有效下标、误差单项指数）：

- `ln_q`（证 $\ln(1+q)\gtrless p$，$q>0$）：下界 $l_n=[n/n]$（$n\ge1$），上界 $u_n=[n+1/n]$（$n\ge0$，$u_0=x$）。
- `arctan_q`（证 $\arctan q\gtrless p$，$q>0$）：下界 $l_n=[2n/2n]$（$n\ge1$；$l_0=0$ 为平凡界，搜索跳过），上界 $u_n=[2n+1/2n+1]$（$n\ge0$，$u_0=x$）。

'arctan 的 $[2n/2n]$ 即对奇函数直接做 Padé：分母自动只剩偶次项、分子只剩奇次项'（奇/偶方程解耦，奇系数方程齐次）。

## 误差函数恒等式（逐 n 符号验证）

记 $G=1+x$（ln）或 $1+x^2$（arctan），$(f-P/Q)' = E/(G Q^2)$，$E = Q^2 - G(P'Q-PQ')$ 是多项式。对每个用到的下标，`err_form` 核验 $E$（上界族取 $-E$）是**单项** $c x^e$ 且 $c>0$：

- ln：$s_n = c\,x^{2n}/((1+x)D_n^2)$、$t_n = c\,x^{2n+1}/((1+x)\tilde D_n^2)$；在 $Q(0)=1$ 规范化下实测 $c=\binom{2n}{n}^{-2}$、$c=\binom{2n+1}{n}^{-2}$（$n\le10$ 逐值核过，测试钉住 $n\le5$）。
- arctan：$s_n = c\,x^{4n}/((1+x^2)D_n^2)$、$t_n = c\,x^{4n+2}/((1+x^2)\tilde D_n^2)$；系数表（$n=0..4$）：下界 $c\in\{1,4/9,64/1225,256/53361,16384/41409225\}$，上界同序 $\{1,4/25,64/3969,256/184041,16384/147744025\}$，未认闭式（不影响核验——逐证书重算）。

分母无正极点：$n\le50$（ln）/ $n\le34$（arctan）内全部分母系数非负且 $Q(0)=1$（Descartes 判据即足），测试钉住 $n\le20$。误差函数在 $(0,q]$ 上严格正——故恒等式给出严格不等式。

## 插值配对与证书

配对规则（与文章算例逐字节对齐）：'>' 取首个 $l_k(q)\le p$ 的 $k$（单调递增序列下即 $n=1$，$l_1$ 是最弱下界）与首个 $l_m(q)>p$ 的 $m$；'<' 对称取首个 $u_k(q)\ge p$（即 $u_0=x$，若 $p\le x$）与首个 $u_m(q)<p$。权重 $a,b\ge0$、$a+b=1$、$aA_n+bA_m=p$。

证书 `{kind, comp, q, p, n, m, a, b, resid, serr}` 全 Fraction；`resid = aA_n(q)+bA_m(q)-p\ge0$（'>'；'<' 取反）。配对情形 resid=0；当 $p<l_1(q)$（或 $p>u_0(q)$）无同侧逼近可配——退化为单项证书 $n=m$、$a=0,b=1$、resid$=A_m(q)-p>0$。`verify_cert` 重推逼近式、重推误差单项形（含指数与分母极点检查）、重核 resid 恒等式与 serr 自描述，全程 ℚ。

## 与 kernel-spec 的差异（spec 补遗）

1. kernel-spec 原文"取 $m<n$ 使 $l_m(q)>p$"方向颠倒：$l_n$ 单调递增至 ln，越界项必 $m>n$；实测算例还原出的配对是（同侧最弱下标，首个越界下标），文章的 $a$（如 4499/4500、1749/1918）挂在**越界项**上——本实现 cert 的 `b` 即文章的 `a`。
2. 退化情形（$p<l_1$ 或 $p>u_0$）spec 未覆盖：$a l_n + b l_m = p$ 无解，需要 resid 项吸收 $A_m(q)-p$。证书加了 `resid` 字段统一处理。
3. spec 中 "$s_n = x^{2n}/((1+x)D_n^2)$" 的分子系数依赖分母规范化：整系数化 $D$（如 $l_1$ 取 $2+x$）才是裸 $x^{2n}$；$Q(0)=1$ 规范化下是 $c x^{2n}$，$c>0$。核验只要求"正系数单项"，两种规范化都合法。
4. 定义域限 $x>0$（ln 族站端本就只要 $q>1$，artanh/arcoth 经 q~ 归约同理；$x\in(-1,0)$ 时两侧界翻转，族角色互换，本引擎不覆盖）。
