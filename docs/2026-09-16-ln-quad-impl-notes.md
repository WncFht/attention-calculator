# ln_q_quad 落地笔记（2026-09-16）

新类型 `ln_q_quad`（exact 模式专属，站点无此型）：证 `(ln q)⁴ ⋚ bound`，q 为有理数且 q > 1，power 槽携带 q（与 ln_q/ln_q_cube 同）。实现并入 `kernels/ln_pow.py`——ln 幂族共址，矩公式按对数幂次 `lp` 参数化，立方/四次两分支共用同一台矩机。

## 核与矩空间

沿用 ln 族构造：基 `x^m(1-x)^n`、域 [0,1]、分母幂 `s = max(m,n,1)`，核取 `ln³(1+cx)/(1+cx)^s`（c = q−1）——"核的对数幂次恒比目标低一"机制的最后一环由 `u⁻¹` 项产出目标常数。

代入 u = 1+cx：`x^k = c^{−k} Σ_r C(k,r)(−1)^{k−r} u^r`、`dx = du/c`，矩化为 `J_p = ∫₁^q u^p ln³u du` 的和（p = r−s）。闭式：

- p = −1：`J_{−1} = ln⁴q / 4`——目标常数；
- p ≠ −1：`J_p = q^{p+1}·Σ_{i=0}^{3} (−1)^i 3!/(3−i)!·ln^{3−i}q/(p+1)^{i+1} + 6/(p+1)⁴`，即 `q^{pp}(ln³/pp − 3ln²/pp² + 6ln/pp³ − 6/pp⁴) + 6/pp⁴`（pp = p+1）；u=1 边界只动 ln⁰ 项，把它的 `q^{pp}` 因子翻成 `q^{pp}−1`。

故矩空间为 5 维 span{ln⁴q, ln³q, ln²q, ln q, 1}，P 升四次 `a+bx+cx²+dx³+ex⁴` 共 5 个未知量——与立方同论证：4 系数对 5 符号超定，`p=−1` 项在 `s = max(m,n,1)` 下总出现（s−1 ≤ m+n−1 < m+n+4）。代码上 `mu(c,s,k,lp)`/`basis_moment(...,lp)` 按 `lp` 参数化，lp=2 分支逐字复现原立方矩（回归由 test_exact_ln_pow.py 全套兜住）。

矩公式经 200dps 数值核验：`mpmath.quad` 对照 `mu(c,s,k,3)`，c ∈ {1, 1/2, 2, 1/3, 4, 3}、s ≤ 5、k ≤ 7 共 180 组全部吻合至 ~1e-196 以内（最差 c=1/3：4.55e-196）。

## 四次非负判据（Sturm，精确）

立方用的 QQ(√D) 临界值闭式在四次失效（P′ 是三次，P 在临界点的值没有二次域内的闭式），改用 Sturm 实根计数。判据：

**`P ≥ 0 on [0,1]` ⟺ P ≡ 0，或（P 的最低次非零系数 > 0 且开区间 (0,1) 内无奇数重根）。**

证明。必要性：最低次非零系数 c_e 定 P 在 0⁺ 邻域的符号（`P(x) ~ c_e·x^e`，x^e > 0），c_e < 0 则 P 在 (0,ε) 取负；奇数重根恰是变号点，存在内部奇根则在其一侧取负；P(0) < 0 时 c_e = P(0) < 0 同被第一条捕获。充分性：c_e > 0 使 P 在 (0,δ) 为正，无内部奇根则 (0,1) 上符号恒定（偶重根只触零），P > 0 贯穿内部、由连续性端点 P(0),P(1) ≥ 0 自动成立——注意奇数重的端点根也被允许：x = 0 的奇重已由 c_e > 0 吸收（如 x(x²+1)），x = 1 的奇重若使内部取负（(x−1)Q、Q>0）则 c_e = −Q(0) < 0 被第一条捕获。

实现（`quartic_nonneg`）：先剥掉端点因子 x 与 (x−1)（`Poly.exquo` 循环，端点根任意重数均合法），再取平方自由分解（`Poly.sqf_list`，Yun 算法，ℚ 上精确）中**奇数重因子之积** O——O 平方自由且其根集恰为 P 在开区间的奇重根（剥端点后 O(0),O(1) ≠ 0，区间语义无歧义）；`Poly.count_roots(0,1)`（Sturm 序列，ℚ 精确）数 O 在 (0,1) 内根数，为零即非负。判据是充要条件，非充分条件。

交叉验证：随机四次（系数分子 ±40、分母 ≤15）4000 组与独立精确参考 `real_roots(multiple=True)` + 重数奇偶判定**零分歧**；另有 20000 组对数值栅格最小值扫描仅 1 例假分歧（端点 x=1 恰为根，浮点噪声 ~1e-50 低于栅格容差，精确判定正确）。针对用例覆盖：内部偶重根触零 `(2x−1)²(x²+2)/4`、端点奇重根 `x³(1−x)`、端点+内部偶重 `x(1−x)(2x−1)²`、四重内部根 `(x−1/2)⁴` 全部判 True；隐藏内凹 `1−17x²(1−x)²`（P(0)=P(1)=1、内部两个单根）、三重根变号 `(1/2−x)³(x+1)`、双内根 `(x−1/4)(x−1/2)` 全部判 False。

## 参数编码与注册

响应沿用九槽语义再扩两字段：`e_val`/`eu_val` 携带 x⁴ 系数（与 `d_val`/`du_val` 同式，`u_val = lcm(五个分母)`，`*u_val` 为整分子，`*_val` 为约分文本）；`solution` 串续排 `..., e= V`。checker 只读 `*u_val`/`u_val`（`*_val` 是回显文本），`exact_check/ln_pow.py` 按 kind 分派系数键与判据。渲染复用 ln 族版式：分子 `t·x^m(1−x)^n(au+…+eu·x⁴)ln³(1+cx)`、分母 `u′(dx+e)^s`，t/u′ = e^s/u 约 gcd 后印刷。

**接线清单（merge 时由 leader 执行，本任务未动注册文件）**：

- `kernels/__init__.py`：`EXACT_TYPES += "ln_q_quad"`；
- `solve.py`：`FAMILY["ln_q_quad"] = "ln_pow"`；
- `integrand.py`：`constant_mpf["ln_q_quad"] = mp.log(q)**4`（power 槽是 q 本身，不乘系数——同 ln_q_cube 行式）；
